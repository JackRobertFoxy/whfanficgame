# 静室 · A Quiet World — 完整篇 v1.0

以卡斯蒂安为主角的 2D 点击式心理恐怖网页游戏。Phaser 3 + TypeScript + Vite，无后端。电脑与安卓手机浏览器使用同一套静态网页；支持触控、安装到桌面与首次完整缓存后的离线游玩。

基于用户提供的《Warhammer 40k Fanfic Setup.pdf》，完整篇覆盖现代世界线的苏醒、暂住、医生会面、返回公寓、模型广告、记忆重构与三个叙事结局。旧世界以前期回忆交代；不逐章复制全部 120 页。

**18+：** 包含囚禁、严重伤害的非露骨回忆、控制关系与创伤主题。进入前必须确认成年。声音默认关闭，可关闭闪光／抖动／幻视。无色情画面。无脸纸雕人物与冷色场景采用统一的独立游戏视觉方向，不使用此前的写实脸。

## 已实现

- 七章：病房、走廊、公寓客厅、卧室、次日会面、顶层公寓、记忆裂隙。
- 34 个关注点，其中 27 个物件观察、7 个角色对白；15 枚双重认知记忆碎片。
- 早期表达会改变后续回应；最终三个结局各有后日谈，回顾是否向医生透露记忆、是否提出界限。
- 已做选择在回看旧对白时保留，最终陈述可以单独重选；旅程记录可回看最近 400 条叙述。
- 自动／手动本地存档、文件导入导出、Demo v1 存档迁移、坏档与浏览器存储失败处理。
- 安卓竖屏触控按钮、可放大正文、独立场景快捷列表，电脑支持键盘。
- PWA 清单、应用图标、带版本的离线缓存、GitHub Pages 子路径适配、部署工作流与静态发布 ZIP。

目标阅读时长约 30–45 分钟，尚未以真人试玩测量。自动快速点击通关不代表正常游玩时长。

## 本地运行

Node.js 22.12+ 或 24，npm。当前环境 Node 24.19.0／npm 11.9.0。

```sh
cd /workspace/whfanficgame
npm ci
npm run dev
```

```sh
npm test           # 11 项状态、分支与存档测试
npm run build      # 类型检查、生产构建、生成离线包清单与 service worker
npm run preview    # 本机预览生产版本
npm run package    # 输出 release/quiet-world-web-v1.0.zip
```

离线包必须通过 HTTP／HTTPS 服务，不能双击 HTML 当作 file:// 文件运行。安装与 service worker 需要 HTTPS 或本机 localhost。正式电脑与安卓使用同一个 HTTPS 网站。

## 怎么玩

1. 确认成年，选择是否减弱效果。
2. 点场景标记或下方物件按钮，切换「现实记录／我的认知」。
3. 完成观察收集本章碎片，再与角色交谈，按目标前往下一章。
4. 裂隙中收下最后一枚记忆，按明示提示完成三格重构。
5. 选择最终陈述，阅读后日谈；可回看记录或重选最后一句。

Esc 暂停，M 档案，V 切换认知，空格推进；Tab／Enter 操作按钮。移动依靠协助或记忆转场，点击代表注意，不代表卡斯蒂安能步行。手机不要求点中细小画布标记，较大的物件按钮提供同等交互。

存档在当前浏览器。想在电脑与安卓之间转移：设置 → 导出存档文件 → 在另一台设备的设置中导入并确认。没有云账号或自动跨设备同步。读取／导入不会绕过年龄确认。读档不保存对话光标，可重新点击该次互动从头阅读。

## 安卓安装与离线

用安卓 Chrome 打开正式 HTTPS 地址，完成一次加载；设置中的「安装到桌面」可调用系统安装提示，或使用浏览器菜单的安装／添加到主屏幕。安装提示由浏览器决定是否提供。看到「完整离线包已就绪」后，下次断网刷新可继续。清除浏览器站点数据会同时删除离线缓存和本地存档，建议定期导出文件。

这是一款网页／PWA，不是原生 APK。浏览器触控模拟验证与实际安卓真机验证是不同的检查，详见验证记录。

```sh
npm run build
npm run preview -- --port 4173
# 另一终端：根路径预览
DEMO_URL=http://127.0.0.1:4173/ npm run test:e2e
```

默认测试目标为 `http://127.0.0.1:4173/whfanficgame/`，用来模拟 GitHub Pages 子路径。CI 或本机可通过 `DEMO_URL` 指定实际根目录。默认浏览器 `/usr/bin/chromium`，可用 `CHROMIUM_PATH` 指定。测试分别完整跑电脑与 Pixel 7 触控模拟，测试存档导入导出、剧情分支、三个结尾与断网后刷新。

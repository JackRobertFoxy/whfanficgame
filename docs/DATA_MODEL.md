# 当前数据模型 · v1.2

类型位于 `src/types.ts`，手写改编源稿位于 `scripts/narrative/`，生成后的运行数据位于 `src/data/story.json`。

- `Story`：标题、数据版本4、15场景、30碎片、对白映射、三种收尾。
- `StoryScene`：id、章节、时代、陪同角色、入场段落、物件、目标、必要小游戏、下一场提示、时间。
- `Hotspot`：坐标、名称、现实／主观两组段落，以及可选的碎片、对白、小游戏与演出触发。
- `DialogueNode`：角色、正文、选项、片段条件、前序选项标记条件。
- `Choice`：显示文字、完整回应、可选持久标记／收尾ID。
- `Fragment`：id、标题、发现位置、现实／主观摘要、原作对应说明。
- `Ending`：标题、摘要与分段后文。另由早先的录音或安慰选项追加对应记忆。

`GameState.version`为4。持久化场景、视角、已到访／观察／谈话、碎片、选择、条件标记、三格重构、收尾、设置、最近400条记录与四个小游戏的部分进度。`decisions`以“对白ID.节点序号”保存选择标签；回看此前对白重播原结果，不改写已作决定。

存档键为 `quiet-world.save.v4`。缺失时依次读取v3、v2、v1；旧版剧情已废弃，因此只迁移字号、减弱效果，清空旧剧情进度并从病房开始。旧键不删除、不覆盖，读取时明确提示。当前版本的导入／导出正常保留完整进度。读档后声音关闭，当前减弱效果设置优先。

存档校验涵盖版本、ID白名单、唯一性、选项指针、谜题数组、结尾条件与记录长度。损坏数据不覆盖现有状态。文字渲染转义，不执行导入内容。成人确认独立于存档，每次打开仍需确认。

生产构建为每个资源生成内容摘要清单，service worker完整缓存后支持离线重开。导航联网优先，静态资源缓存优先；不会在阅读中强制刷新。更新前存档，关闭本站所有标签再打开，以便等待中的缓存版本接管。

# 完整篇场景流程 · v1.0

```mermaid
flowchart TD
 A[18+ 内容提示与年龄确认] -->|离开| X[安全结束页]
 A -->|确认成年| P[新故事或存档恢复]
 P --> H[01 病房：监护仪／身份卡／罗伯特回忆]
 H -->|3 碎片＋对白，医护协助| C[02 走廊：警徽／转移安排]
 C -->|2 碎片＋对白，协助至公寓| L[03 客厅：电脑／照料记录]
 L -->|2 碎片＋对白，协助回卧室| B[04 卧室：预约／警校照片]
 B -->|2 碎片＋对白，次日| D[05 会面：暂停权／空白记录]
 D --> D1{透露记忆还是保留来历}
 D1 -->|disclosed| R[后续记住已透露的经历]
 D1 -->|private| R2[后续保留尚未交出的部分]
 R --> T[06 顶层公寓：安排／门禁／模型广告]
 R2 --> T
 T --> T1{要求先询问还是先联系提图斯}
 T1 -->|asserted| W[界限回应]
 T1 -->|contact| W2[联系请求回应]
 W --> F[07 裂隙：留白的纸／最后一枚碎片]
 W2 --> F
 F --> M[15 碎片齐全：三格重构]
 M -->|错误反馈，不消耗| M
 M -->|witness／ordinary／model| E[回到当下：电话中的陈述]
 E --> E1[第一句自己的话＋后日谈]
 E --> E2[今晚的距离＋后日谈]
 E --> E3[正确的词＋后日谈]
 E1 --> Q[回看旅程／记忆或重选最后一句]
 E2 --> Q
 E3 --> Q
 Q --> E
```

每章先观察关键物件获得碎片，再完成角色对白；前六章达到条件后才能进入新章。裂隙须先得到第十五枚碎片，再确认重构。已到访章可回看；回看既有选择只播放已选回应，不改写此前决定。

早期陪伴／界限、是否透露记忆、是否提出要求会通过条件对白与后日谈被引用。没有善恶评分，不把暂时保留来历设为坏结局。

场景转移依赖协助或记忆转场，裂隙是主观认知空间。原作时间压缩与新增桥段见 GDD。

# v1.2 场景流程

```mermaid
flowchart TD
 A[18+确认] --> H[01 病房：醒来与同名身份]
 H --> P[02 泰坦军械间：受伤前／接线]
 P --> C[03 旧囚室：另一个萨拉马斯]
 C --> W[04 返家：温水与热汤]
 W --> N[05 床头灯：真诚安慰令对方恐惧]
 N --> T[06 两天期限：临时交给提图斯]
 T --> L[07 客厅：藏住自己的喜欢]
 L --> B[08 卧室：学习现代名称]
 B --> D[09 问诊：不说出穿越来历]
 D --> Q[10 手机：提图斯代拨给萨拉马斯]
 Q --> R[11 被接回：安心却更加陌生]
 R --> V[12 战舰医疗舱：救援记录排序]
 V --> S[13 书房：萨拉马斯打开订婚相册]
 S --> M[14 广告：模型／骰子／价格]
 M --> F[15 感官重叠：整理30枚碎片]
 F --> E{回应回到家的人}
 E --> E1[几厘米高的战争：再看模型]
 E --> E2[唯有安宁：真心喜欢、安心入睡]
 E --> E3[明早九点：保守秘密、继续复诊]
```

每章找齐本地关键碎片、完成必要小游戏，再完成角色谈话即可前进。已到访场景可回看；此前选项保留已选回应。军械间移动受伤前的卡斯蒂安；现代移动陪同者，设备由他人代操作。记忆裂隙是短暂主观重叠，实际位置仍在公寓沙发。

结尾整理的三个来源为旧世界亲历（witness）、学会的现代常识（ordinary）、电视商品（model）。分类不改变身体，不揭露来历，不消除对萨拉马斯的真心依恋。剧情依据见 [v1.2改编说明](NARRATIVE_V1_2.md)。

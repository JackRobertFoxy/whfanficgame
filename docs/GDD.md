# 静室 · 当前游戏设计 v1.2

《静室》是以卡斯蒂安为主角的2D点击式心理恐怖同人游戏，使用Phaser 3、TypeScript与Vite，电脑和安卓浏览器共用GitHub Pages地址。视觉保留抽象无脸纸雕人物、冷色现代定点空间与哥特式过去场景；过去阿斯塔特始终戴全封闭动力甲头盔。

核心悬疑是：一个带着旧世界记忆的人，占据了同名现代警察的身体。他真心喜欢现代萨拉马斯、依赖照料，害怕被认出与被抛弃；身边人却把他的平静、陌生常识和改变的喜好理解为严重创伤。人物动机与原作页码对应见 [叙事依据](NARRATIVE_V1_2.md)。

玩家控制注意、观察和表达。每章入场叙述交代人物位置、时间与目的；点击物件获得现实信息与卡斯蒂安认知；关键物件留下碎片，角色谈话提出完整语境下的选择。收集、必要设备游戏和谈话完成后可前进，旧章可回看。

故事从病房经过去囚室回到现代照料，展开真诚依恋、临时暂住、学习常识、问诊隐瞒、等待接回、原主录音与模型广告，最终在公寓中收束。详细十五章流程见 [流程图](SCENE_FLOW.md)。三个收尾均不改变残障与依赖，不把关系改成逃离或独立任务。

四个小游戏分别是战锤沉思者接线、救援记录排序、现代订婚相册密码与手机联系人解锁。线索明确存在，无错误惩罚；手机可点按数字和上下移动，不依赖拖拽。现代设备由其他角色代操作。军械间可移动受伤前的主角，其余场景移动陪同者，主角转移始终依赖协助。

演出包括细微雨尘／呼吸、有限横向人物移动、颜色变化、轻微镜头晃动、短暂主观覆盖与本地合成声。声音默认关闭；入口可减弱演出，设置可放大文字、暂停、导入导出、读写进度与回看。18+确认在加载画布前完成。

当前规模15章、30枚碎片、65互动点、四个小游戏与三种收尾；正文32,674字符，目标是足够完整的阅读流程，实际游玩时长尚未真人测量。没有RPG战斗、配音、骨骼动画、云账号或原生APK。
